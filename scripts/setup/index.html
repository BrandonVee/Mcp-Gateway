MCP Gateway首次启动

连接你的数据服务

连接 PostgreSQL 与 Redis，创建管理员账号，然后进入管理后台。

1验证部署身份

运行 docker logs mcp-gateway 获取密钥。请通过 HTTPS 或本机 / SSH 隧道完成初始化。

2PostgreSQL

请先创建专用数据库和账号，账号须能创建 schema 和数据表。地址必须从容器内可访问。

高级：使用完整连接 URL

填写后覆盖上方参数；用户名和密码中的特殊字符需进行 URL 编码。自签证书需通过容器挂载 CA 配置。

3Redis

高级：使用完整连接 URL

填写后覆盖上方参数；需要 Redis 读写与 Lua 脚本权限。

4管理员账号

密码至少 16 个字符。已有数据库中的管理员账号不会被覆盖。

配置与应用密钥保存在 /app/data 持久化卷中。进入后台后，在“系统设置”填写 HTTPS 访问地址、注册和可信上游。
